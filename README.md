# edge-vla-bench

Robot VLA models on an 8 GB Jetson Orin Nano (Super devkit): what fits, how fast, how accurate.
Columns follow vla.cpp (arXiv 2606.08094) Table III so rows compare directly. Scope, protocol,
prior art, and the license and commit of every model and tool are in [PLAN.md](PLAN.md).
Criticisms we expect, and how each is handled, are in [CRITIQUES.md](CRITIQUES.md).

This repo holds scripts, configs and docs. It contains no model weights.

**All accuracy results are LIBERO simulation results, not real-robot results.**

## Prior work

- vla.cpp, arXiv 2606.08094, github.com/VinRobotics/vla.cpp (Apache-2.0): the runtime, eval loop and table
  columns this repo builds on. We do not claim to be first.
- eetmie/jetson-orin-nano-vla (MIT): ONNX/TensorRT exports of SmolVLA and X-VLA for the 8 GB Nano.
- arXiv 2604.24447: cross-hardware VLA leaderboard without the Orin Nano.
- LIBERO (Liu et al., arXiv 2306.03310 [verify]); lerobot (Hugging Face); SmolVLA (arXiv 2506.01844 [verify]);
  X-VLA (arXiv 2510.10274 [verify]); Evo-1 [verify citation].

## Layout

```
scripts/capture_setup.py   fixed-setup capture (JetPack/L4T, power mode, clocks, runtime, ...) -> JSON
scripts/run_row.sh         one row on the Jetson: setup capture, vla-server, tegrastats, LIBERO client, peak RSS
scripts/run_reference.sh   fp16 reference row on the NUC (upstream PyTorch checkpoint)
scripts/libero_eval.py     LIBERO loop with per-request timing (vla.cpp client boundary)
scripts/summarize.py       run dir -> row.json; all row.json -> markdown table; list of all attempts
scripts/analyze.py         per-task successes, Wilson intervals, latency spread, row vs reference
scripts/dump_prompts.py    verbatim LIBERO task prompts
Makefile                   `make all`: recompute rows, table, attempts list and analysis from run dirs
results/jetson/<row>/<utc>/  one directory per run (setup.json, steps.jsonl, episodes.jsonl, row.json, logs)
results/nuc/<row>/<utc>/     fp16 reference runs
runtimes/                  third-party runtimes, cloned at pinned commits (git-ignored)
```
